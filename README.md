# 宅飲みミックス

持っているお酒・割り材を選ぶと、今すぐできる飲み方を提案してくれる静的Webアプリです。

- お酒を2つ、割り材を2つまでプルダウンで選べます(空欄でもOK)
- 選ぶたびに、その場で提案が更新されます
- 提案は2段構成です
  - **こんな飲み方もできるよ**: 梅酒ソーダ割り・焼酎の麦茶割り・ビールの残りにレモンを絞るだけ、といった気軽な家飲みの組み合わせ。あらかじめ用意したものに加え、選んだお酒×割り材の組み合わせに応じて自動生成もされます
  - **本格派向けカクテル**: ジントニックやハイボールなど、定番のバー風カクテル(全材料が揃ったときだけ表示)

## 技術構成

- 素のHTML/CSS/JS(ビルド不要、ES Modules)
- データは`data/`配下の静的ファイル(`ingredients.js`・`cocktails.json`・`casualCombos.json`)
- 依存パッケージなし。テストはNode.js組み込みの`node --test`を使用

## 開発

```bash
npm test   # 単体テストを実行
npm run dev  # http://localhost:5173/ で開発用サーバーを起動
```
