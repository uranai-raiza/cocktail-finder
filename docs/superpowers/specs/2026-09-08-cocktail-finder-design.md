- 日付: 2026-09-08

- 保存先: `D:\AI-Generated\家飲みカクテルファインダー\`

## 目的

家で晩酌・宅飲みをする、酒に詳しくない一般ユーザーが、手持ちのお酒・割り材にチェックを入れるだけで、今すぐ作れるカクテルのレシピ(材料・分量・手順)を絞り込み表示できる完全フロントエンドの静的Webツール。

## 技術方針

- 素のHTML/CSS/JS。ビルドツール・フレームワーク・バックエンド・DBは使わない。
- データはJSONファイル(`cocktails.json`)で静的に保持する。
- デプロイ(Vercel/Netlify/GitHub Pages等)は本設計のスコープ外。今回はローカルでの作成・動作確認までとし、公開は別途ユーザーの指示があってから行う。

## 材料マスタ(チェックリスト、18項目)

### お酒(8)
ジン、ウォッカ、ラム、テキーラ、ウイスキー、トリプルセック、カンパリ、コーヒーリキュール

### 割り材(10)
炭酸水、トニックウォーター、ジンジャーエール、コーラ、オレンジジュース、グレープフルーツジュース、パイナップルジュース、レモン/ライム果汁、グレナデンシロップ、ミルク

氷・砂糖・塩など「常備している前提」の材料はチェックリストに含めず、絞り込み判定にも使わない(レシピの表示には含めてよい)。

## カクテルデータ(26種、確定リスト)

## UI構成

- 1ページ構成。上部(またはスマホでは上、PCでは左)に材料チェックリスト(お酒/割り材の2グループ)。
- 下部(スマホ)/右側(PC)に、絞り込まれたレシピ一覧をカード形式で表示。各カードに名前・材料(分量つき)・手順を表示。
- 該当0件のとき「作れるカクテルがありません。材料を追加してみてください」を表示。
- レスポンシブ: CSS Grid/Flexboxで、幅に応じてチェックリストとレシピ一覧を縦積み⇔横並びに切り替える(ブレークポイント目安: 768px)。

## データフロー

1. `cocktails.json` を fetch で読み込み、メモリ上に保持する。
2. チェックボックスの `change` イベントで、チェック済み材料キーの集合を再計算する。
3. 各カクテルの `requiredIngredients` が、チェック済み集合の部分集合であるものだけを抽出する純粋関数 `filterCocktails(cocktails, checkedSet)` を通す。
4. 抽出結果でレシピ一覧を再描画する。

## エラー処理

- `cocktails.json` の fetch に失敗した場合、画面に「データを読み込めませんでした」を表示する。
- 想定外の入力(不正なチェックボックス値等)は発生しない設計のため、追加のバリデーションは行わない。

## テスト

- `filterCocktails` 関数をNode.jsの単体テストで検証する(空選択→0件、部分一致→除外、完全一致→含む、材料が多い場合も含む、等)。
- 実装後、ローカルサーバーを起動し、ブラウザ(PC幅・スマホ幅)で実際にチェック操作・表示崩れ・該当0件表示を確認する。

## スコープ外(MVP後の任意要件)

- お気に入り保存(localStorage)

これらは `requiredIngredients` を使ったデータ構造のままで後から追加できる設計とする。
